# Prompt 分层模板 / Layered Prompt Block Template

> 用法：固定层（角色卡/场景卡/风格锚点）整片复用，写一次调一次；可变层（动作/镜头运动/光影）每镜独立，改一镜只动一镜。复制下方分块填写即可。

## 固定层（整片复用）

```
【角色卡】（旁白音色、口吻、语速）
例：性别中性，27岁，语调松弛像对着语音备忘录随口说话，语速平缓自然，无说教感。

【场景卡】（场景设定、时代氛围、道具表）
例：千禧年旧桌面（CRT卧室角落），白天内：浅米白木纹桌面，大屁股CRT显示器居中，
屏幕亮Windows98蓝天白云启动界面；桌面左侧半透明翻盖手机与CD随身听，右侧半杯
带气泡的橘子汽水，前景一叠千禧年旧杂志。

【风格锚点】（整体美术风格、色调、质感）
例：复古海报质感，CRT 淡蓝暖光，千禧年玻璃线稿动画风格。
```

## 可变层（每镜独立）

```
【动作】（本镜主体动作，可核对）
例：铁锈工业厂区上立着老式机器人，一枚火箭正升空，空中悬浮着旧汽车与红蓝线框全息地球。

【镜头运动】（推 / 拉 / 移 / 固定）
例：推。

【光影】（本镜光线与氛围）
例：屏幕边缘泛淡蓝玻璃光晕；CRT 暖光映在指尖。
```

## 组合示例（Clip 5，引用真实分镜剧本）

```
【角色卡】性别中性，27岁，语调松弛像对着语音备忘录随口说话，语速平缓自然，无说教感。
【场景卡】异星草地：亮绿草地天空，一台屏幕泛粉紫彩虹眩光的CRT电视压在前景。
【风格锚点】复古海报质感 + 铁锈工业厂区科幻风。

【动作】老式机器人立在厂区中景，一枚火箭正升空，空中悬浮着旧汽车与红蓝线框全息地球；
火箭持续升空，全息地球缓慢旋转。
【镜头运动】推。
【光影】CRT 电视屏幕粉紫彩虹眩光缓慢流动，映亮前景草叶。

【硬约束】禁止生成任何字幕，禁止生成背景音乐；中文旁白，声音不要戛然而止，留自然尾音。
```

## 填写要点

- 固定层引用不重复：可变层里不需要再写角色卡，写"【固定层】见项目级角色卡"即可。
- 穿帮只查对应层：画面穿帮改【动作】，色调不对改【风格锚点】，曝光不对改【光影】。
- 硬约束单独成块，全片统一，不随可变层改动。

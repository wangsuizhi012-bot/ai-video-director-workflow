# 实战案例：《千禧信号·自复制AI反思》

> 一支 22 镜 4 场的叙事短片：从千禧年旧桌面的 CRT 雪花，到现代数字桌面被拆成 token 的世界，再到人与服务器"生存逻辑几乎一模一样"的反思。本案例是 ai-video-director-workflow 的诞生地，全部数据来自真实制作过程，无虚构功能。

## 一、项目背景

- **主题**：AI 自复制反思——千禧年记忆 vs 当下 token 化世界，"拆到底层看，其实我们俩的生存逻辑几乎一模一样"。
- **结构**：22 Clip / 4 场（场1 千禧年旧桌面 → 场2 现代数字桌面 → 场3 抽象可视化序列 → 场4 收束）。
- **规格**：1920x1080，30fps，总时长 245 秒（成片约 4:05）。
- **硬约束**：禁止字幕、禁止背景音乐、中文旁白留自然尾音（不戛然而止）。
- **音色**：性别中性，27 岁，语调松弛像对着语音备忘录随口说话，语速平缓自然，无说教感。

## 三、工作流如何落地（六阶段对应）

1. **点子输入**：主题"千禧年 vs AI 自复制反思"一句话起步；硬约束（禁字幕/禁BGM/留尾音）第一时间写入任务单。
2. **稿子输出**：Agent 产出完整旁白稿，按场/镜拆解（22 镜 4 场），每镜附镜头描述与旁白。
3. **审稿**：导演逐段反馈（哪里好、哪里不好），Agent 修改至定稿冻结。
4. **分镜与生成**：Agent 拆镜 → 写分层 Prompt（固定层角色/场景/风格锚点 + 可变层动作/镜头/光影）→ 为每镜写一句话验收标准 → 提交 ComfyUI H3 工作流生成。
5. **导演台审核**：ByteCut Director 预填看板，逐镜对照验收标准打勾；"不能用/需改进"片段反馈指向具体条目。
6. **迭代与成片**：按反馈单变量修改（只动对应层）→ 版本快照 → 重生成 → 满意后 Remotion 总装成片。

## 四、迭代过程实录要点

- **22 镜长序列策略**：先全量生成建立全局观，再集中修改最影响观感的镜头（对应 `iteration.md` 纪律 3）。
- **单变量修改**：画面问题只改可变层对应项；音色问题只改角色卡，不碰画面层。
- **版本快照**：每镜 prompt + 结果成对存档，回退对比有据。
- **中途插入新内容**：允许回到审稿闭环补充镜头，再整改进成片。

## 六、经验与边界

- **收益**：验收标准前置让 22 镜的返工可归因；分层 Prompt 让单镜修改不污染全片；预填看板让导演全程只做决策。
- **边界（不虚构）**：IndexTTS-2 音色克隆为落地计划中的环节；ByteCut Director 为外部工作台，本仓库沉淀的是其背后的方法论而非其功能实现。ComfyUI 生成、Remotion 总装、预填看板均为真实落地环节。

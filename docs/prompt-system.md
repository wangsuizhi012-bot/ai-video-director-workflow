# Prompt 分层体系 / Layered Prompt System

> 把 Prompt 拆成"固定层"与"可变层"：**固定层**承载可复用的角色卡、场景卡、风格锚点；**可变层**承载每镜独有的动作、镜头运动、光影。分层后，穿帮只查对应层，不污染其他层。

## 为什么分层

AI 视频的 Prompt 越长，微调越难：改一个动作，风格、场景、光影全跟着变，出了问题不知道改哪。分层把"不变的"和"每镜变的"分开：

- **固定层（Fixed Layers）**：整片复用，写一次、调一次，全片生效。
- **可变层（Variable Layers）**：每镜独立，改一镜只动一镜。

## 分层结构

| 层 | 类型 | 内容 | 示例 |
|---|---|---|---|
| 角色卡 | 固定层 | 旁白音色、口吻、语速 | 性别中性，27岁，语调松弛像对着语音备忘录随口说话，语速平缓自然，无说教感 |
| 场景卡 | 固定层 | 场景设定、时代氛围、道具表 | 千禧年旧桌面（CRT卧室角落），白天内；CRT显示器、翻盖手机、CD随身听、橘子汽水、旧杂志 |
| 风格锚点 | 固定层 | 整体美术风格、色调、质感 | 亮天蓝玻璃 UI / 暖光 / 千禧年玻璃线稿动画质感 |
| 动作 | 可变层 | 本镜主体动作 | 老式机器人立在厂区中景，一枚火箭正升空 |
| 镜头运动 | 可变层 | 推/拉/移/固定 | 推 |
| 光影 | 可变层 | 本镜光线与氛围 | 屏幕边缘泛淡蓝玻璃光晕；CRT 暖光映在指尖 |

## 分层模板示例（引用真实分镜）

固定层（整片复用）：

```
【角色卡】旁白音色：性别中性，27岁，语调松弛像对着语音备忘录随口说话，语速平缓自然，无说教感。
【场景卡】千禧年旧桌面（CRT卧室角落），白天内：浅米白木纹桌面，大屁股CRT显示器居中，屏幕亮Windows98蓝天白云启动界面；桌面左侧半透明翻盖手机与CD随身听，右侧半杯带气泡的橘子汽水，前景一叠千禧年旧杂志。
【风格锚点】复古海报质感，CRT 淡蓝暖光，千禧年玻璃线稿动画风格。
```

可变层（每镜独立，Clip 5 为例）：

```
【动作】铁锈工业厂区上立着老式机器人，一枚火箭正升空，空中悬浮着旧汽车与红蓝线框全息地球；画面前景是亮绿草地与一台屏幕泛粉紫彩虹眩光的CRT电视。
【镜头运动】推。
【光影】粉紫彩虹眩光缓慢流动，全息地球在空中缓慢旋转。
```

> 示例镜头来自实战案例《千禧信号·自复制AI反思》Clip 5 的真实分镜剧本。

## 好处

1. **穿帮只查对应层**：画面穿帮（动作不对）只改"动作"层；色调不对只改"风格锚点"；曝光不对只改"光影"。
2. **不污染其他层**：改 Clip 5 的动作，不会波及 Clip 1–4 的固定层与其他镜的可变层。
3. **固定层可复用**：下一支视频换"场景卡"就能复用同一套角色卡与风格锚点，起步更快。

## 反模式

| ❌ 反模式 | ✅ 正解 |
|---|---|
| 整段 Prompt 一大坨，改一处全重写 | 固定层/可变层分块，改一处动一处 |
| 每镜都重写风格描述 | 风格锚点只写一次，引用即可 |
| 验收失败时凭感觉乱改整段 | 按穿帮现象定位到层，只改该层 |

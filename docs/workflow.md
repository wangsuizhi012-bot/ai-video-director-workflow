# 六阶段工作流详解 / The Six-Stage Workflow

> 核心原则：**人做决策，AI 做执行**。导演不写稿、不写提示词、不渲染，只负责输入点子、审核产出、给出反馈；Agent 负责从点子到成片的全部执行。

## 总览

```
Stage 1 点子输入 → Stage 2 稿子输出 → Stage 3 审稿 → Stage 4 分镜与生成 → Stage 5 导演台审核 → Stage 6 迭代与成片
```

| 阶段 | 输入 | 输出 | 负责人 | 一句话要点 |
|---|---|---|---|---|
| 1. 点子输入 | 灵感/主题/素材 | 结构化任务单 | 导演（人类） | 只丢点子，不丢成品要求 |
| 2. 稿子输出 | 任务单 | 旁白/文案稿 | Agent | 一次成稿，附镜头拆解建议 |
| 3. 审稿 | 稿子 | 修改意见 + 定稿 | 导演（人类） | 指出哪里好、哪里不好，不改写 |
| 4. 分镜与生成 | 定稿 | 分镜图 + 提示词任务 | Agent | 出分镜图，提交提示词任务到后端 |
| 5. 导演台审核 | 分镜与初生成物 | 逐镜验收结论 | 导演（人类） | 可视化看板逐镜挑出不能用/需改进片段 |
| 6. 迭代与成片 | 验收反馈 | 迭代版本 + 最终成片 | Agent | 按反馈改提示词→重生成→满意→成片 |

---

## Stage 1：点子输入

**输入**：一个想法、一段经历、一条新闻、一组素材照片/音频，甚至一句话。

**输出**：结构化任务单（主题、时长目标、语气基调、硬约束）。

**负责人**：导演（人类）——每天发现的点子随手丢给 Agent，先不追求完整。

**要点**：
- 点子不需要完整，一句"做一个关于千禧年与 AI 的反思短片"就可以起步。
- 硬约束此时就要写清（如：禁字幕、禁背景音乐、中文旁白留自然尾音），避免后期返工。
- Agent 收到点子后会追问关键参数（时长、风格、旁白音色），导演只需回答决策性问题。

## Stage 2：稿子输出

**输入**：结构化任务单。

**输出**：旁白/文案稿，建议同时给出可拆成镜头的段落结构。

**负责人**：Agent——基于任务单直接产出完整初稿。

**要点**：
- Agent 一次成稿，不要挤牙膏式分段输出。
- 稿子应按"场/镜"结构拆解，方便后续直接进入分镜（参考案例：22 镜 4 场）。
- 初稿长度按目标成片时长估算（245s 成片 ≈ 旁白字数与语速匹配）。

## Stage 3：审稿

**输入**：Agent 稿子。

**输出**：修改意见 + 定稿。

**负责人**：导演（人类）——逐段指出"哪里好、哪里不好"，**不替 Agent 改写**。

**要点**：
- 反馈要具体："第三段的比喻太抽象，换成具体物件"；不要只说"写得不好"。
- 导演只做判断与方向，文字落笔归 Agent，这正是"人决策、AI 执行"的体现。
- 审稿通过后定稿冻结，进入分镜阶段；中途可插入新内容，但要重新走审稿闭环。

## Stage 4：分镜与生成

**输入**：定稿。

**输出**：分镜图（参考图/场景图）+ 提示词任务，提交到后端生成队列。

**负责人**：Agent。

**要点**：
- Agent 根据定稿拆镜头，为每镜写分层 Prompt（固定层 + 可变层，见 `prompt-system.md`）。
- 为每镜写一句话验收标准（见 `review-rubric.md`），生成前写好。
- 生成任务提交到后端（如本地 ComfyUI 工作流），Agent 轮询结果并回填资产路径。

## Stage 5：导演台审核

**输入**：分镜与初生成物（参考图、旁白、成片片段）。

**输出**：逐镜验收结论（通过 / 需改进 / 不能用）。

**负责人**：导演（人类）——在可视化看板上逐镜验收，打勾推进。

**要点**：
- 每镜一张卡片，状态点（IMG/END/AUD/LTX/VID/OK）逐项打勾（见 `director-board.md`）。
- 导演只验收，不填表；Agent 每完成一步自动回填资产并打勾。
- 挑出"不能用/需改进"的片段，反馈理由要指向具体层（画面/旁白/节奏）。

## Stage 6：迭代与成片

**输入**：验收反馈。

**输出**：迭代版本 + 最终成片。

**负责人**：Agent——执行修改，导演验收，循环直到满意。

**要点**：
- 遵守迭代纪律：单变量迭代、版本快照、批量/逐镜策略（见 `iteration.md`）。
- 满意即止，不要无限打磨；成片规格在任务单中提前定死（如 1920x1080 / 30fps）。
- 允许中途插入新内容：回到 Stage 1–3 重新过审稿，再整改进成片。

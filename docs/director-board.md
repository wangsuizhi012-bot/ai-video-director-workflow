# 导演台看板规范 / Director Board Specification

> 导演台是"人做决策、AI 做执行"的落地界面：**镜头卡片 + 状态点**，Agent 每完成一步回填资产并打勾，导演只验收。可视化推进，告别纯命令行流水线。

## 一、核心结构：镜头卡片（Shot Card）

每个镜头一张卡片，包含：

| 字段 | 说明 |
|---|---|
| 镜号 | Clip 1 / Clip 2 …（与剧本镜头一一对应） |
| 所属场 | 场景1｜千禧年旧桌面（CRT卧室角落）… |
| Prompt | 分层 Prompt（固定层引用 + 可变层） |
| 验收标准 | 一句话通过标准（谁/动作/道具/衔接） |
| 状态点 | IMG / END / AUD / LTX / VID / OK |
| 资产回填 | 参考图/旁白/成片路径 |

## 二、状态点：打勾推进

每镜一条流水线，六步打勾：

| 状态点 | 含义 | 完成标志 |
|---|---|---|
| IMG | 分镜图 | 本镜分镜图（描述/草图）已生成 |
| END | 场景图/参考图 | 本镜场景底图或参考图已就位 |
| AUD | 旁白 | 本镜旁白已生成（音色、语速符合角色卡） |
| LTX | 生成参数 | 本镜生成参数/提示词任务已提交到后端 |
| VID | 成片 | 本镜视频片段已生成并回填路径 |
| OK | 验收通过 | 导演在导演台对照验收标准打勾 |

推进规则：

1. Agent 每完成一步，**回填资产（参考图/旁白/成片路径）并打勾**。
2. 导演只做两件事：看卡片、打 OK（或给反馈）。
3. 状态点必须顺序推进：VID 未就绪不能打 OK，AUD 未就绪不能进 LTX。

## 三、回填资产规范

- 每步完成必须回填**可访问路径**（本地绝对路径或资产库引用），不是口头描述。
- 回填格式建议：`AUD: temp/tts/narration_01.mp3`、`VID: output/clip01_v1.mp4`。
- 回填即快照：prompt、资产路径、验收结论一起存档，供迭代回退（见 `iteration.md`）。

## 四、导演只验收（Director Approves Only）

- 导演不填表、不写提示词、不渲染；所有执行落在 Agent。
- 导演的产出只有三种：**打勾通过 / 指出未达标条目 / 给出新方向**。
- 未达标反馈指向验收标准的具体条目，避免笼统"不行"。

## 五、结合 ByteCut Director 实战

《千禧信号·自复制AI反思》使用 ByteCut Director 预填看板落地本规范：

1. **预填**：Agent 读取分镜剧本，预填 22 张镜头卡片（22 Clip / 4 场，总时长 245s），写入看板 JSON（`qianxi-signal.json`）。
2. **资产回填**：按视频编号 00219~00240 推断 clip01~22 归属，回填 11 张场景图（`qianxi-v2-*.png`）、22 段旁白（`narration_01~22.mp3`）至对应镜头卡片。
3. **打勾推进**：IMG/END/AUD/LTX/VID/OK 逐镜推进，导演只在 OK 点介入验收。
4. **硬约束固化在看板**：禁字幕、禁背景音乐、中文旁白留自然尾音，写进固定层与卡片说明，全片统一执行。

> 说明：ByteCut Director 为外部可视化工作台；本仓库聚焦其背后的方法论——预填、回填、打勾、只验收。

## 七、常见误区

| ❌ 误区 | ✅ 正解 |
|---|---|
| 导演动手改提示词、改参数 | 导演只验收、给方向，Agent 执行 |
| 不写验收标准就打 OK | OK = 对照验收标准逐条通过 |
| 步骤完成不回填资产 | 每步回填路径，看板可追溯 |
| 状态点跳跃（没 VID 直接 OK） | 顺序推进，每步打勾 |
